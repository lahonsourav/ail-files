# Code of Conduct

Be kind, assume good faith, and keep feedback about the work, not the person.

We do not accept harassment, insults, or discrimination of any kind, in issues, pull requests, or anywhere the project is discussed. People who cannot follow this may be removed from the project's spaces.

Report a problem privately to the maintainers through the repository's Security tab ("Report a vulnerability") or by a message to the repository owner on GitHub.

This is a short statement in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
